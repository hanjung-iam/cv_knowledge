00 · 起點 影像分類

電腦看到的是一堆數字

名詞影像分類（Image Classification）：給電腦一張圖片，讓它從一組事先固定好的類別中，選出最符合的一個標籤（label），例如 cat、dog。
名詞像素（pixel）：影像上的一個小點。彩色影像的每個像素有紅、綠、藍 3 個數字（3 個顏色通道），每個數字是 0（黑）～ 255（白）的整數。

一張寬 248、高 400 的彩色照片，對電腦來說是：

248 × 400 × 3 = 297,600 個數字

任務：把這 297,600 個數字變成一個標籤，例如「cat」。

為什麼這件事對電腦很難？

人一眼就認得出貓，但電腦比對的是數字。同一隻貓換個角度、光線、姿勢，那些數字就跟著改變。CS231n 列出的難點：

視角變化

Viewpoint：同一個物體從不同角度拍，看起來完全不同

尺度變化

Scale：同一類物體的實際大小差很多

形變

Deformation：很多物體不是剛體，可以扭曲（例如貓的姿勢）

遮蔽

Occlusion：物體可能只露出一小部分

光照

Illumination：光線對像素的影響非常劇烈

背景雜亂

Background clutter：物體和背景融在一起

類內差異

Intra-class variation：同一類（例如椅子）外觀差很多

CS231n 也強調：這份清單並不完整

目標好的模型要對上面這些變化保持 invariant（不變）：輸入的樣子變了，答案不變；同時又要對不同類別之間的差異保持敏感。

解法的大方向：Data-driven approach

排序數字可以寫成明確的步驟，但「怎麼認出一隻貓」很難寫成程式規則。所以改成像教小孩一樣：給電腦看很多已經標好答案的例子，讓學習演算法自己學出每個類別的樣子。

1 · Input

準備 N 張影像，每張都標好 K 個類別中的一個。這批資料叫 training set。

2 · Learning

用 training set 學出每個類別的樣子，叫做 training a classifier（訓練分類器）。

3 · Evaluation

讓分類器預測一批它從沒看過的影像（test set），再和真正的答案比對。

名詞Ground truth：每張影像真正的標籤，也就是「標準答案」。
名詞Accuracy（準確率）：預測正確的比例。這是影像分類最常用的評估標準。

01 · 第一站 KNN

Nearest Neighbor：找最像的那一張

就像帶著整本有標註的圖鑑去考試：遇到不認識的東西，就翻圖鑑找長得最像的那一頁，照抄它的名字。

  1. 訓練（train）：什麼都不學，只是把所有訓練影像和它們的標籤存起來。CIFAR-10 就是存下 50,000 張。
  2. 預測（predict）：把新影像和每一張訓練影像比較，找出「距離」最近的那一張，直接採用它的標籤。
名詞距離（distance）：用一個數字表示兩張圖「差多少」。數字越小越像；兩張圖完全一樣時是 0。下一頁介紹怎麼算。

01 · 第一站 KNN

怎麼算「有多像」① L1 距離

名詞L1 距離：把兩張影像逐個像素相減，取絕對值（去掉正負號），再全部加起來。
d1(I1, I2) = Σp |I1p − I2p|
  • I1、I2：要比較的兩張影像（已攤平成一串數字）
  • p：第幾個像素；I1p 是影像 1 在第 p 個位置的數值
  • | |：絕對值；Σp：對每一個像素都算一次，再加總

算一次看看示意

假設影像只有 4 個像素：

像素 1像素 2像素 3像素 4
影像 I110203040
影像 I212202550
相減取絕對值20510

L1 距離 = 2 + 0 + 5 + 10 = 17

真實的 CIFAR-10 影像有 3,072 個數字，所以一次比較要加總 3,072 項；兩張圖完全一樣時，結果是 0。

01 · 第一站 KNN

怎麼算「有多像」② L2 距離

名詞L2 距離：逐個像素相減，平方，全部加起來，再開根號。就是幾何上兩點之間的直線距離（歐氏距離）。
d2(I1, I2) = √( Σp (I1p − I2p)2 )

用上一頁的例子示意：差值 2、0、5、10 平方後是 4、0、25、100，加總 129，開根號 ≈ 11.4。

實際使用時可以省略開根號：開根號不會改變「誰比較近」的順序，找到的最近鄰居還是同一張。

兩者差在哪？

L2 對差異比較不寬容：差異被平方之後，大的差異會被放大。所以它寧可接受很多個中等的差異，也不願意接受一個很大的差異。示意

兩張圖的差異L1L2
4 個像素各差 55+5+5+5 = 20√(25×4) = 10
只有 1 個像素差 2020√400 = 20

L1 認為兩種情況一樣遠；L2 認為「一個大差異」比較遠。

L1、L2 都屬於同一個距離家族（p-norm）。要用哪一種，沒有標準答案，要實際測試 — 這就是後面要談的 hyperparameter。

01 · 第一站 KNN

從 NN 到 KNN：讓 k 個鄰居投票

名詞KNN（k-Nearest Neighbor）：找出距離最近的 k 張訓練影像，讓它們投票，票數最多的標籤就是答案。k = 1 時就是前面的 Nearest Neighbor。
  • 為什麼要投票？只看最近的一張，很容易被異常值（outlier：混在別類中間的少數資料點）帶偏。例如一個混在藍色群裡的綠點，會在它周圍形成一小塊錯誤的「孤島」。
  • k 越大，決策邊界越平滑，越不容易被異常值影響，在新資料上的表現可能比較好。
  • CS231n 的建議：實務上幾乎都應該用 KNN，而不是只看一張的 NN。
名詞決策邊界（decision boundary）：把空間分給各個類別的分界線。新資料落在哪一區，就被判成哪一類。

為什麼這麼差：像素距離 ≠ 長得像

CS231n 把一張臉平移、遮住、調暗。這三張圖和原圖的 L2 像素距離都一樣：

  • 對人來說，平移和調暗的還是同一張臉，被遮住的那張卻差很多 — 但像素距離分不出來。
  • 把 CIFAR-10 依 L2 距離排列，影像主要是按整體色調和背景聚在一起：狗和青蛙因為都在白色背景上而靠得很近。
  • NN 的示範中，10 張測試圖大約只有 3 張找到同類別的最近鄰；一張馬頭的最近鄰是一輛紅色的車，推測是兩者都有很強的黑色背景。
CS231n 的結論：
必須超越 raw pixel

raw pixel＝沒有經過任何處理的原始像素值。光比較它們，抓不到影像裡「是什麼」。

01 · 第一站 KNN

k 要設多少？— Hyperparameter

名詞Hyperparameter（超參數）：無法從資料中直接學到、必須由人來選的設定。例如 KNN 的 k、要用 L1 還是 L2。通常沒有明顯的正確答案，只能多試幾個值，看哪個最好。

那可以拿 test set 來試，看哪個 k 最好嗎？不行。

比喻：期末考與模擬考

test set 就像期末考。如果你反覆看期末考卷，再照考卷內容調整讀書方法，最後考高分也不代表真的學會，只代表你「背了考卷」。

在機器學習裡

依 test set 的表現調 hyperparameter，等於把 test set 當成訓練資料在用（overfit to the test set）。測出來的成績會過度樂觀，真正部署後可能明顯變差。

名詞Overfitting（過擬合）：模型擬合到資料裡的雜訊，而不是背後真正的關係，所以在那份資料上很好、在新資料上變差。
名詞Generalization（泛化）：模型在沒看過的資料上的表現。test set 只在最後用一次，才能可靠地衡量它。

01 · 第一站 KNN

正確做法：用模擬考選設定

名詞Validation set（驗證集）：從 training set 切出一小部分，當作「假的 test set」，專門用來選 hyperparameter。

CIFAR-10 的例子：對每個候選的 k（1、3、5、10、20、50、100）都在 validation set 上評估，選出最好的 k，最後只在 test set 上跑一次。

名詞Cross-validation（交叉驗證）：訓練資料很少時，只切一份 validation 的結果不穩定。改成輪流讓每一份資料都當一次 validation，再把結果取平均。

CS231n 的 5-fold 實驗圖中，在那份資料上 k ≈ 7 最好。因為 cross-validation 的計算成本高，實務上比較常用單一的 validation split。

第一站小結：KNN 的優點與問題

✓ 優點

  • 很簡單，容易實作和理解
  • 訓練時間是零：只需要把資料存起來

✗ 問題

KNN 的取捨方向是反的：實務上我們更在乎「預測快」，訓練慢一點沒關係。下集的主角深度神經網路剛好相反：訓練很貴，但訓練完之後分類新影像很便宜。

02 · 第二站 Linear classifier

Score function：像素進去，分數出來

名詞Score function（分數函數）：把影像的像素，轉成「每個類別一個分數」的函數。分數最高的類別就是答案。
名詞參數（parameter）：函數裡可以調整的數字。訓練資料是給定的、不能改；我們能調整的只有參數 W 和 b。
符號形狀（CIFAR-10）意思
x3072 × 1一張影像攤平成一行（32 × 32 × 3）
W　權重（weights）10 × 3072每個類別一列；每一列有 3,072 個權重，對應每一個像素數值
b　偏差（bias）10 × 1每個類別一個數字，直接加到分數上，不和像素相乘

好處：學完之後就可以丟掉整個 training set，只保留 W 和 b；分類一張新圖只要一次矩陣乘法加一次加法（下一頁用小例子示範怎麼算）。

一張貓怎麼變成分數

CS231n 的簡化例子：影像只有 4 個像素，3 個類別。W 的每一列負責一個類別：把那一列的 4 個權重和 4 個像素逐一相乘、加總，再加上那個類別的 b，就是它的分數。

cat 分數 = 0.2×56 + (−0.5)×231 + 0.1×24 + 2.0×2 + 1.1 = −96.8
明明是貓，cat 分數卻最低、dog 最高 — 這組 W 很差，模型「深信」這是一隻狗。

02 · 第二站 Linear classifier

W 到底在做什麼？三種理解方式（上）

① 加權總和：喜歡或討厭某些顏色

每個權重對應「某個位置的某個顏色」。權重是正的，那裡的顏色越強、分數越高（喜歡）；是負的，分數越低（討厭）。例如 ship 的藍色通道權重偏正，紅、綠通道偏負。

② 幾何：高維空間中的分界線

把每張影像看成 3,072 維空間中的一個點。W 的每一列對應一條分界線（高維中是超平面）：線上的點分數是 0，沿箭頭方向分數越來越高。改 W 的那一列，線會旋轉；改 b，線會平移。沒有 b 的話，所有線都被迫通過原點。

三種理解方式（下）：③ 模板比對

名詞內積（inner product）：兩串一樣長的數字，對應位置相乘，再全部加起來。例如 (1, 2) 和 (3, 4) 的內積是 1×3 + 2×4 = 11示意。W 的一列和 x 相乘，就是在算內積。
名詞模板（template）：W 的一列有 3,072 個數字，排回 32 × 32 × 3，就能看成一張「圖」— 這個類別的模板（也叫 prototype）。它是學出來的，不一定是訓練集裡的某一張圖。

影像和模板「亮在同樣的地方」時，對應位置相乘的總和會比較大 → 分數高 → 越吻合。所以算分數，就是拿影像去和每個類別的模板比對。

03 · 第三站 Loss

Loss function：對預測不滿意的程度

名詞Loss function（損失函數，也叫 cost function 或 objective）：一個把「模型在 training set 上的預測有多差」變成一個數字的函數。預測越差，loss 越高。
L = (1/N) Σi Li + λ R(W)

Data loss（黃色部分）

Li：第 i 張訓練圖的 loss，比較它的分數和正確標籤。
(1/N) Σi：把全部 N 張的 loss 取平均。
衡量：預測和標籤吻不吻合。

Regularization loss（紫色部分）

只看權重 W、和資料無關，用來表達「偏好哪一種 W」。λ 決定它有多重要。
先放著，本站後半再介紹。

Li 怎麼定義有很多種選擇。接下來介紹兩種最常見的：Multiclass SVM loss 和 Softmax（cross-entropy）loss。

concepts / loss-function
03 · 第三站 Loss

Multiclass SVM loss：正確類別要贏得夠多

想法：正確類別的分數，要比每一個錯誤類別的分數，都至少高出一個固定的差距 Δ。

名詞Margin（Δ）：要求正確類別領先的最小差距。領先不到 Δ，就要被扣分。
Li = Σj ≠ yi max(0, sj − syi + Δ)
  • sj：第 j 個類別的分數（score function 算出來的）
  • yi：第 i 張圖的正確類別；syi 就是正確類別的分數
  • Σj ≠ yi：對每一個錯誤類別都算一次，再加起來
  • max(0, ·)：取 0 和括號內較大的那個 → 括號內是負的，就當成 0
白話：括號裡的 sj − syi + Δ，代表這個錯誤類別「離安全距離還差多少」。
領先已經 ≥ Δ → 結果 ≤ 0 → 不扣分。
領先不到 Δ → 差多少就扣多少。

03 · 第三站 Loss

逐步計算：為什麼 Li = 0 + 8？

CS231n 的例子：三個類別的分數 s = (13, −7, 11)，正確的是第一類，Δ = 10。

  1. 正確類別的分數：syi = 13。要求：每個錯誤類別都要比 13 至少低 10，也就是要 ≤ 3（數線上紅色區域的左邊）。
  2. 錯誤類別 −7：max(0, −7 − 13 + 10) = max(0, −10) = 0。13 比 −7 高出 20，超過要求的 10 → 已達標，不扣分。
  3. 錯誤類別 11：max(0, 11 − 13 + 10) = max(0, 8) = 8。13 雖然比 11 大，但只高出 2，離要求的 10 還差 8 → 扣 8。
  4. 把每個錯誤類別的結果加起來：Li = 0 + 8 = 8

注意：SVM 只在意差距有沒有達到 Δ。只要領先達到 10，結果就是 0；領先得再多，也不會帶來額外的好處。

03 · 第三站 Loss

SVM loss 的兩個細節

① 名稱：hinge loss

max(0, ·) 這種「在 0 截斷」的函數叫 hinge loss（像門的鉸鏈，在 0 折一下）。另有 squared hinge loss：改用 max(0, ·)²，沒達到 margin 時懲罰更重；不平方的版本比較標準，但有些資料集平方版效果更好，可以用 cross-validation 決定。

② Δ 要設多少？直接設 1.0

這不需要調。原因：

  • W 的大小會直接影響分數之間的差距：把 W 整體放大，差距就放大；縮小，差距就縮小。
  • 所以 margin 設 1 還是 100，在某種意義上沒有差別 — W 可以任意縮放。
  • 真正要調的，是允許 W 長到多大，也就是本站後半的 λ。Δ 和 λ 控制的其實是同一個取捨。

為什麼還需要 Softmax？

SVM 留下的不方便

SVM 給的是沒有校準過的分數（數值大小沒有固定的意義）。例如 cat、dog、ship 得到 (12.5, 0.6, −23.0)。12.5 代表模型有多大把握？分數本身不容易解讀。

→

Softmax 的做法

把分數轉成每個值都在 0～1 之間、加總為 1 的數字，例如 (0.9, 0.09, 0.01)。一眼就看得出模型對每個類別有多少信心。

兩個好處

① 可以解讀

輸出像「機率」，可以看成模型對每個類別的信心程度（不過這個「機率」要打引號，原因在本站後面說明）。

② 永遠不滿足

SVM 只要 margin 達標就不再在意；Softmax 的 loss 會一直督促「正確類別的機率再高一點」— 正確類別的機率永遠可以再高一點。

Softmax classifier＝同樣的 score function Wx，只是換成用 softmax 解讀分數、用 cross-entropy 當 loss。接下來兩頁分別介紹。

03 · 第三站 Loss

Cross-entropy loss：正確答案的機率越高越好

名詞Cross-entropy loss（交叉熵損失）：先用 softmax 算出正確類別的機率 p，loss 就是 −log p（log 是自然對數）。

為什麼用 −log p？

  • p = 1（模型完全確定正確答案）→ −log 1 = 0，沒有 loss
  • p 越接近 0 → loss 越大，而且沒有上限
  • 所以：模型給正確答案的機率越高，loss 就越低
上一頁的例子：正確類別是第三類，p = 0.353
→ Li = −log(0.353) = 1.04

名稱：SVM classifier 用 hinge loss；Softmax classifier 用 cross-entropy loss。「softmax loss」是很常見的簡稱，但不精確 — softmax 只是把分數壓成機率的那一步，不是 loss。

例子：分數 (10, −2, 3)，第一類正確，Δ = 1

SVM：margin 已經滿足，loss = 0。就算分數改成 (10, −100, −100) 或 (10, 9, 9)，SVM 也一樣是 0。

還有一個問題：好的 W 不只一組

假設某組 W 已經把每張訓練圖都分對，而且 margin 都達標，每個 Li = 0。現在把 W 全部乘以 2：

所有分數都變成 2 倍，差距也跟著變 2 倍（例如 15 → 30），margin 照樣達標，loss 還是 0。也就是說，能讓 loss = 0 的 W 有無限多組。要選哪一組？

名詞Regularization（正規化）：在 loss 裡額外加上一項只跟權重有關、跟資料無關的懲罰 R(W)，用來表達「我們偏好哪一種 W」。這就是前面 loss 公式的紫色部分。

比喻：兩個學生考試都拿滿分。一個每一科都理解了，另一個只靠背某幾題的答案。只看分數分不出差別，但遇到新題目時，前者比較可靠。Regularization 就是在「答對」之外，再加一條偏好：不要過度依賴少數幾個特徵。

03 · 第三站 Loss

最常見的懲罰：L2 regularization

名詞L2 regularization：把 W 的每一個元素平方，再全部加起來，當作懲罰：
R(W) = Σk Σl Wk,l2

名稱裡的 L2，和 KNN 那一站的 L2 距離一樣，都是「平方再加總」的算法（這裡是平方的 L2 norm，不開根號）。

名詞λ（regularization strength）：決定懲罰項有多重要的 hyperparameter。沒有簡單的設定方式，通常用 cross-validation 決定。
例：輸入 x = (1, 1, 1, 1)
w₁ = (1, 0, 0, 0)
只看第一個維度		內積 = 1R = 1² + 0² + 0² + 0²
= 1.0
w₂ = (0.25, 0.25, 0.25, 0.25)
平均看所有維度		內積 = 1R = 4 × 0.25²
= 0.25 ✓

兩者的預測完全一樣，但 L2 penalty 偏好 w₂：每個輸入維度都考慮一點，而不是強烈依賴少數幾個。這通常能改善在 test 影像上的泛化表現、減少 overfitting。

完整的 loss：L = (1/N) Σi Li + λR(W)。加上 regularization 之後，loss 不可能剛好是 0（除非 W 全是 0）— 它的目的本來就不是讓 training loss 更低，而是讓模型在新資料上更好。

03 · 第三站 Loss

Softmax 的「機率」為什麼要加引號？

回到 Softmax。它的輸出看起來像機率，但有多集中，會隨權重的大小改變：

分數取指數正規化（normalize）後的「機率」
原本的權重(1, −2, 0)(2.71, 0.14, 1)(0.7, 0.04, 0.26)
權重全部減半(0.5, −1, 0)(1.65, 0.37, 1)(0.55, 0.12, 0.33)：變得更分散
  1. 分數是 W 乘上 x 算出來的。W 全部減半，分數也全部減半 → 同一張圖的「機率」變得更平均。
  2. W 有多大，又受 regularization 控制：λ 越大 → 權重越小 → 「機率」越平均；權重趨近 0 時，輸出接近均勻分布。
  3. 所以同一張圖，換一個 λ 訓練，「機率」就會不一樣。
結論：把 softmax 的輸出看成信心程度。和 SVM 一樣，分數的排序可以解讀，絕對數值不能直接解讀。輸出 0.9，不代表「有 90% 的機率是對的」。

感覺坡度：什麼是 gradient

名詞斜率（導數）：一維函數 f(x) 在某一點的瞬間變化率 — x 往右動一點點時，f 跟著變化多少。
df(x)/dx = limh→0 [f(x+h) − f(x)] / h

h 是「一點點」：把 x 加上 h，看 f 變了多少，再除以 h；數學上 h 要趨近於 0。

名詞Gradient（梯度）：輸入有很多個數字時（例如 W 的 30,730 個），對每一個數字各算一個斜率（叫 partial derivative，偏導數），排成一個向量，就是 gradient。
gradient 指向函數上升最陡的方向。我們要讓 loss 下降，所以往 負 gradient 的方向走。（SVM 的 max 會造成折角，嚴格來說不可微，實務上用 subgradient，當成 gradient 使用即可。）

# CS231n：所有神經網路函式庫的核心
while True:
  weights_grad = evaluate_gradient(
    loss_fun, data, weights)
  weights += - step_size * weights_grad
  • 第 2 行：用目前的 weights 和資料，算出 gradient
  • 第 4 行：往負 gradient 走一步；step_size 決定步伐大小

gradient 怎麼算？兩種方法

Numerical gradient（數值梯度）Analytic gradient（解析梯度）
做法每個參數各加上一個很小的 h（例如 1e-5），看 loss 變了多少用微積分推導出 gradient 的公式，直接代入計算
精確度近似值（h 不可能真的是 0）精確

缺點無法擴展到大模型推導和實作容易出錯

numerical 有多慢？

CIFAR-10 的 linear classifier 有 30,730 個參數，每個參數都要各算一次 loss，再加上原本那一次 → 光是走一步，就要評估 30,731 次 loss。現代神經網路動輒數千萬個參數，根本無法這樣做。

實務上的標準做法：gradient check

實際訓練用 analytic gradient（快），再拿 numerical gradient 和它比對，確認公式和程式寫對了。至於 analytic gradient 怎麼有效率地算 → 本站後半的 backpropagation。

04 · 第四站 Optimization

一步要走多遠？Learning rate

名詞Learning rate（學習率，也叫 step size）：gradient 只告訴我們方向，沒有告訴我們要走多遠。每一步走多遠，就是 learning rate。

CS231n 從同一組隨機的 W 出發（loss 2.200718），試不同的 step size 各走一步：

  • 太小（1e-10）：穩定，但幾乎沒進展（2.200652）
  • 剛好（1e-06）：這組範例中最低（1.647802）
  • 太大：走過頭（overstep），loss 反而變高；1e-01 時暴增到 25392.214036

CS231n：learning rate 是訓練神經網路時最重要、也最令人頭痛的 hyperparameter 之一。

Mini-batch：不必看完全部資料才走一步

問題：大型資料集（例如 ILSVRC）的訓練影像有 120 萬張。只為了走一步，就算完全部資料的 loss，太浪費。

名詞Mini-batch gradient descent：每次只用一小批（batch）資料計算 gradient 就更新一次。（截至 CS231n 筆記撰寫時）典型的做法是從 120 萬張中取 256 張。

為什麼可行？因為訓練資料彼此相關。思想實驗：如果 120 萬張其實只是 1000 張不同影像（每類一張）、每張各複製 1200 份，那麼用全部算出的 gradient，和只用那 1000 張算的完全一樣。真實資料不會這樣重複，但一小批的 gradient 仍然是完整 gradient 的好近似，而且可以更頻繁地更新，收斂快得多。

  • SGD（Stochastic Gradient Descent）嚴格來說是 batch 只有一筆的情況；但大家說 SGD 時，通常指的是 mini-batch。
  • batch size 通常依記憶體決定，或直接設 32、64、128 這類 2 的次方（很多向量化運算，也就是一次處理一整批數字的寫法，在這種大小時跑得比較快）。

先理解導數：它代表「敏感度」

每個變數的導數，代表整個運算結果對這個變數有多敏感。

例子：f(x, y) = xy，x = 4、y = −3 → f = −12

∂f/∂x 讀作「f 對 x 的偏導數」：只讓 x 變動一點點時，f 變化多少。

∂f/∂x = y = −3：x 增加一點點 h，f 會減少 3h。
∂f/∂y = x = 4：y 增加一點點 h，f 會增加 4h。

注意：導數只描述「無限小」的變化，不能拿來預測大幅改變輸入時會發生什麼事。

名詞Local gradient（局部導數）：一個小運算的輸出，對它自己的輸入的導數。只看這一個小運算，不管整個式子。

三種基本運算的 local gradient

運算對 x對 y
f = xy（乘法）yx
f = x + y（加法）11
f = max(x, y)x 比較大時是 1，否則 0y 比較大時是 1，否則 0

乘法：對一個輸入的導數，剛好是另一個輸入的值。這一點後面會用到。

Chain rule：把每一段的導數相乘

例子：f = (x + y) × z，x = −2、y = 5、z = −4。拆成兩個小運算（gate）：q = x + y、f = q × z。

名詞Chain rule（連鎖律）：把各段的 gradient 相乘，就得到整體的 gradient：∂f/∂x = ∂f/∂q × ∂q/∂x。

綠色：forward pass，數值從輸入流向輸出
紅色：backward pass，gradient 從輸出往回流

  1. Forward：q = −2 + 5 = 3；f = 3 × (−4) = −12。
  2. 從輸出開始：f 對自己的 gradient 是 1。
  3. 乘法 gate f = q × z：對 z 的 local gradient 是 q = 3；對 q 的是 z = −4。
  4. 加法 gate q = x + y：local gradient 都是 1 → x、y 的 gradient 都是 −4 × 1 = −4。

04 · 第四站 Optimization · Backprop

Backprop 好用的原因：每個 gate 只管自己

名詞Backpropagation（反向傳播）：反覆套用 chain rule，從輸出往回，有效率地算出整個運算對每個輸入的 gradient。

每個 gate 都是「局部」的

gate 拿到輸入後，可以立刻、獨立地算出兩件事：自己的輸出值，以及自己的 local gradient。它完全不需要知道整個電路長什麼樣子。backward 時，它收到「上游傳來的 gradient」，乘上自己的 local gradient，再往回傳。

gate 之間在「傳話」

上一頁的加法 gate 收到 −4，意思是：整個電路希望它的輸出變小，力道是 4。它把 −4 乘上 1 傳給 x、y。如果 x、y 照著負的 gradient 變小，q 就變小；因為 z 是負的，f 就會變大。

實作時的兩個注意事項

  • 存下 forward 的中間值（cache）：backward 時會用到。
  • 分岔處的 gradient 要相加：同一個變數在式子裡被用到好幾次時，往回流的 gradient 要累加，不能覆蓋。

CS231n 強調：幾乎永遠不需要在紙上把整個式子完整地微分；只要拆成小段，每段各自算 local gradient 就好。

三種常見 gate 的規律

CS231n 用一個電路示範：下面每張圖的綠字是 forward 的值，紅字是 backward 的 gradient，輸出端收到的 gradient 都是 2.00。

add：原封不動分給大家

local gradient 是 +1，所以把輸出的 gradient 原封不動分給所有輸入：兩個輸入都拿到 2.00。

max：只給最大的

只傳給 forward 時值最大的輸入：z = 2 比 w = −1 大，所以 z 拿到 2.00，w 拿到 0。

mul：交換

local gradient 是另一個輸入的值：x 的 gradient = y 的值 −4.00 × 2.00 = −8.00。

mul 的反直覺效果：一個輸入很小、另一個很大時，小的輸入會拿到很大的 gradient，大的輸入反而拿到很小的 gradient。下一頁說明這為什麼重要。

04 · 第四站 Optimization · Backprop

mul gate 帶來的提醒：資料前處理

為什麼尺度會影響訓練

權重和輸入相乘（w × x）。依 mul gate 的規律，權重的 gradient 跟著輸入 x 的大小變化：輸入都乘以 1000，權重的 gradient 也變成 1000 倍，learning rate 就得調小同樣的倍數。

名詞Data preprocessing（資料前處理）：把資料送進模型之前，先調整它的中心位置和尺度。

① Centering（減去平均）

先算出所有訓練影像的平均影像（mean image），再從每張影像減掉它 → 像素範圍大約變成 −127～127。CS231n 說這一步比較重要。

② Scaling（縮放）

再把每個輸入特徵縮放到 −1～1 的範圍。

名詞索引（一）：序章、KNN、Linear classifier

影像分類：從固定的類別中，替一張圖選出一個標籤
像素（pixel）：影像上的一點；彩色影像每點有紅、綠、藍 3 個 0～255 的數字
標籤（label）／ground truth：每張影像正確的類別
Data-driven approach：不寫規則，給電腦看有標籤的例子，讓它自己學
Training set／Test set：用來學的資料／最後評估用、只用一次的資料
Accuracy：預測正確的比例
L1 距離：逐像素相減取絕對值，全部加總
L2 距離：逐像素相減平方，加總後開根號（直線距離）
KNN：找最近的 k 張訓練圖投票；k = 1 是 Nearest Neighbor
決策邊界：把空間分給各類別的分界線
Hyperparameter：無法從資料學到、要由人來選的設定（k、λ、learning rate…）
Validation set：從 training set 切出、用來選 hyperparameter 的「模擬考」
Cross-validation：輪流讓每一份資料當 validation，再取平均
Overfitting：擬合到雜訊，在那份資料上好、在新資料上變差
Generalization（泛化）：在沒看過的資料上的表現
參數（parameter）：模型裡可以調整、從資料學出來的數字（W、b）
Score function：把像素轉成每個類別一個分數的函數，例如 f = Wx + b
內積：兩串數字對應位置相乘再加總
模板（template）：W 的一列排回影像形狀，可看成該類別學出來的「圖」
模式（mode）：同一類別裡幾種明顯不同的樣子

名詞索引（二）：Loss、Optimization

Loss function：把「預測有多差」變成一個數字；越低越好
Data loss：所有訓練圖 loss 的平均
Margin（Δ）：SVM 要求正確類別領先的最小差距；通常設 1.0
Hinge loss：max(0, ·) 這種在 0 截斷的函數；SVM loss 用它
Softmax：取指數再除以總和，把分數變成 0～1、加總為 1 的「機率」
Cross-entropy loss：正確類別「機率」p 的 −log p
正規化（normalize）：在 softmax 中指「除以總和，讓加總為 1」
Regularization（正規化）：loss 中只看權重的懲罰，表達對 W 的偏好
L2 regularization：所有權重平方後加總，偏好小而分散的權重
λ：regularization strength，懲罰項的權重
Optimization：找出讓 loss 最小的參數
Convex：碗狀的函數；SVM loss 是，神經網路的 loss 不是
Gradient：每個參數各一個斜率排成的向量；指向上升最陡的方向
Gradient descent：反覆算 gradient、往反方向走一小步
Learning rate（step size）：每一步走多遠
Mini-batch／SGD：每次只用一小批資料算 gradient 就更新
Gradient check：用 numerical gradient 檢查 analytic gradient 有沒有寫錯
Local gradient：一個小運算的輸出對自己輸入的導數
Chain rule：把各段的導數相乘，得到整體的導數
Backpropagation：用 chain rule 從輸出往回，算出每個輸入的 gradient
Data preprocessing：送進模型前，調整資料的中心和尺度
