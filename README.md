# CV Knowledge — Computer Vision LLM Wiki

以 Computer Vision 為主題、由 LLM 維護的個人知識庫（LLM Wiki pattern）。

- `CLAUDE.md`：schema，包含 Wiki 結構、寫作與引用規範、ingest / lint / 簡報 workflow
- `wiki/`：Wiki 本體（從 `wiki/index.md` 開始瀏覽）
- `tools/`：lint 與關聯圖腳本
- `slides/`：以 Wiki 為知識來源產生的 HTML 教學簡報
- `report/process-journal.md`：流程中遇到的問題、修正與反思

原始資料（`raw/`）因版權與檔案大小考量，不納入版本控制；各來源的出處見 `wiki/sources/`。
