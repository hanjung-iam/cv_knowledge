## 一段話摘要

### classification

這是 CS231n 的入門篇，對象是**沒有 Computer Vision 背景的人**。它定義了 Image Classification 問題，說明為什麼這個問題對電腦來說很難，並提出 data-driven approach：不寫規則，而是從有標籤的資料中學習。接著用最簡單的 Nearest Neighbor／kNN 分類器當作第一個 baseline，順帶介紹 hyperparameter、validation set、cross-validation 等機器學習的基本紀律。最後指出 raw pixel 距離反映的是背景和顏色，而不是語意，所以**必須超越 raw pixel**。這是後續學習特徵、走向 CNN 的動機。

## 主要貢獻（對本 Wiki 而言）

### classification

- 定義 Image Classification，並說 detection、segmentation 等任務可以化約成分類 [CS231n classification "Image Classification"]
- 列出影像分類的七種難點，包括 viewpoint、scale、deformation 等 [CS231n classification "Image Classification"]
- 提出 data-driven approach 與 input → learning → evaluation 的流程 [CS231n classification "Image Classification"]
- 介紹 NN／kNN 分類器、L1 與 L2 距離 [CS231n classification "Nearest Neighbor Classifier"; CS231n classification "k - Nearest Neighbor Classifier"]
- 說明調整 hyperparameter 的正確方式：validation set、cross-validation，test set 只能用一次 [CS231n classification "Validation sets for Hyperparameter tuning"]
- 示範 pixel 距離與語意相似度不一致，包含 t-SNE 視覺化 [CS231n classification "Pros and Cons of Nearest Neighbor classifier" 圖]
