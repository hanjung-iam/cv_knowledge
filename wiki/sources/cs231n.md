## classification

### 讀取方式

`classification.pdf` 是用 Microsoft Print to PDF 存的，文字被轉成向量外框，抽不出來，所以**文字以 `.md` 為準**。PDF 只用來看圖，共有 12 張。

### 一段話摘要

這是 CS231n 的入門篇，對象是**沒有 Computer Vision 背景的人**。它定義了 Image Classification 問題，說明為什麼這個問題對電腦來說很難，並提出 data-driven approach：不寫規則，而是從有標籤的資料中學習。接著用最簡單的 Nearest Neighbor／kNN 分類器當作第一個 baseline，順帶介紹 hyperparameter、validation set、cross-validation 等機器學習的基本紀律。最後指出 raw pixel 距離反映的是背景和顏色，而不是語意，所以**必須超越 raw pixel**。這是後續學習特徵、走向 CNN 的動機。

### 主要貢獻

- 定義 Image Classification，並說 detection、segmentation 等任務可以化約成分類 [CS231n classification "Image Classification"]
- 列出影像分類的七種難點，包括 viewpoint、scale、deformation 等 [CS231n classification "Image Classification"]
- 提出 data-driven approach 與 input → learning → evaluation 的流程 [CS231n classification "Image Classification"]
- 介紹 NN／kNN 分類器、L1 與 L2 距離 [CS231n classification "Nearest Neighbor Classifier"; CS231n classification "k - Nearest Neighbor Classifier"]
- 說明調整 hyperparameter 的正確方式：validation set、cross-validation，test set 只能用一次 [CS231n classification "Validation sets for Hyperparameter tuning"]
- 示範 pixel 距離與語意相似度不一致，包含 t-SNE 視覺化 [CS231n classification "Pros and Cons of Nearest Neighbor classifier" 圖]

### 關鍵結果

| 設定 | 指標 | 數值 | 位置 |
|---|---|---|---|
| NN 分類器、L1 距離、CIFAR-10 | accuracy | 38.6% | classification "Nearest Neighbor Classifier" |
| NN 分類器、L2 距離、CIFAR-10 | accuracy | 35.4% | classification "Nearest Neighbor Classifier" |
| 隨機猜測（10 類） | accuracy | 10% | classification "Nearest Neighbor Classifier" |
| 人類在 CIFAR-10 上的表現（估計值） | accuracy | 約 94% | classification "Nearest Neighbor Classifier" |
| （截至 CS231n 筆記撰寫時）state-of-the-art CNN、CIFAR-10 | accuracy | 約 95% | classification "Nearest Neighbor Classifier" |
| 5-fold cross-validation 選 k | 最佳 k | 約 7 | classification "Validation sets for Hyperparameter tuning"（圖說） |

注意：Summary 段落把 NN 的結果寫成「about 40%」，這是 38.6% 的約略說法 [CS231n classification "Summary"]。Wiki 一律引用 38.6%。

## linear-classify

### 讀取方式

`linear-classify.pdf` 是用瀏覽器「另存為 PDF」存的，文字可以抽取，但 **MathJax 公式在抽出的文字中會消失**，所以**文字和公式以 `.md` 為準**。PDF 只用來看圖，共有 7 張。

**已知的筆誤**：「Practical Considerations」把 Rifkin et al. 2004 寫成「Rikin」，但連結指向的是 Rifkin 的論文 [CS231n linear-classify "Practical Considerations"]。

### 一段話摘要

這篇是從 kNN 走向神經網路的轉折點。它建立了「**score function + loss function → 最佳化**」的框架，後面的神經網路和 CNN 都沿用這套框架。內容包括：用最簡單的線性映射 $f(x) = Wx + b$ 當作 score function，並從加權總和、幾何、template matching 三個角度理解它；介紹兩種常見的 loss（Multiclass SVM 的 hinge loss，以及 Softmax 的 cross-entropy loss）；用 L2 regularization 表達對小而分散權重的偏好。學到的模板（兩個頭的馬、紅色的車）暴露了 linear classifier 表達能力的極限，為神經網路埋下伏筆。

### 主要貢獻

- 提出「score function + loss function → 最佳化」的框架 [CS231n linear-classify "Linear Classification"]
- 定義 linear score function $f(x_i, W, b) = W x_i + b$，並指出 CNN 也用同樣的方式把像素映射成分數 [CS231n linear-classify "Parameterized mapping from images to label scores"]
- 從三個角度理解 linear classifier：加權總和、幾何分界線、template matching [CS231n linear-classify "Interpreting a linear classifier"]
- 用模板視覺化說明 linear classifier 的極限：兩個頭的馬、紅色的車 [CS231n linear-classify "Interpreting a linear classifier"]
- 介紹 bias trick 和 mean subtraction 前處理 [CS231n linear-classify "Interpreting a linear classifier"]
- 介紹 Multiclass SVM（hinge）loss 和 L2 regularization [CS231n linear-classify "Multiclass Support Vector Machine loss"]
- 說明 Δ 可以固定為 1.0，並說明它和 binary SVM 的關係 [CS231n linear-classify "Practical Considerations"]
- 介紹 Softmax classifier、cross-entropy 的兩種詮釋、數值穩定技巧 [CS231n linear-classify "Softmax classifier"]
- 比較 SVM 和 Softmax：局部性的差別、「機率」受 λ 影響 [CS231n linear-classify "SVM vs. Softmax"]

### 關鍵結果

這篇是概念性的筆記，**沒有報告任何模型在資料集上的 accuracy**。筆記裡的數字都是說明用的範例：

| 範例 | 數值 | 位置 |
|---|---|---|
| 4 像素的貓圖，cat／dog／ship 分數 | −96.8／437.9／61.95（ship 的驗算值是 60.75，見下方討論紀錄） | linear-classify "Interpreting a linear classifier" 圖 |
| SVM loss 範例，分數 (13, −7, 11)，Δ = 10 | $L_i$ = 8 | linear-classify "Multiclass Support Vector Machine loss" |
| 同一筆資料的 SVM loss 和 Softmax loss | 1.58／1.04（自然對數，兩者不可比較） | linear-classify "SVM vs. Softmax" 圖 |
| L2 penalty：$w_1$ = (1,0,0,0) 與 $w_2$ = (0.25,0.25,0.25,0.25) | 1.0／0.25 | linear-classify "Multiclass Support Vector Machine loss" |

## optimization-1

### 讀取方式

和 linear-classify 一樣，用瀏覽器「另存為 PDF」存檔：**文字和公式以 `.md` 為準**，PDF 只用來看圖，共有 6 張。

### 一段話摘要

這篇補上學習框架的第三個元件：optimization。它先把 loss 看成一片高維的地形（SVM 是分段線性的 convex 碗，神經網路則是 non-convex），再比較三種策略：random search、random local search、following the gradient。核心想法是 iterative refinement：從隨機的權重出發，一步一步改進。接著介紹計算 gradient 的兩種方法（numerical 與 analytic）、gradient check、step size（learning rate）的取捨，最後是 gradient descent 和 mini-batch／SGD。結尾預告下一篇的 backpropagation。

### 主要貢獻

- 提出「score function + loss function + optimization」三個元件，並預告換成神經網路時，後兩者大致不變 [CS231n optimization-1 "Introduction"]
- 視覺化 loss landscape；SVM loss 是分段線性、convex；神經網路是 non-convex [CS231n optimization-1 "Visualizing the loss function"]
- 比較三種最佳化策略；提出 iterative refinement 和蒙眼下山的比喻 [CS231n optimization-1 "Strategy #1: A first very bad idea solution: Random search"]
- 比較 numerical 和 analytic gradient；介紹 gradient check [CS231n optimization-1 "Computing the gradient analytically with Calculus"]
- 說明 step size（learning rate）的取捨 [CS231n optimization-1 "Computing the gradient numerically with finite differences"]
- 介紹 gradient descent、mini-batch、SGD 的命名慣例、batch size 的選法 [CS231n optimization-1 "Gradient Descent"]

### 關鍵結果

CIFAR-10，linear classifier + SVM loss：

| 設定 | 指標 | 數值 | 位置 |
|---|---|---|---|
| Random search，1000 次 | test accuracy | 約 15.5%（程式回傳 0.1555） | optimization-1 "Strategy #1: A first very bad idea solution: Random search" |
| Random local search，1000 次 | test accuracy | 21.4% | optimization-1 "Strategy #2: Random Local Search" |
| 不同 step size 走一步，原本 loss 2.200718 | loss | 1e-6 時最低 1.647802；1e-1 時 25392.214036 | optimization-1 "Computing the gradient numerically with finite differences" |
